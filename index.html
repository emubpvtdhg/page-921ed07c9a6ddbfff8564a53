使用场景

跨境办公与远程协作

访问代码仓库、云文档、会议软件时，选择延迟更低的香港、日本或新加坡节点。团队版可把办公网段做成固定路由，减少每人单独改规则。

流媒体与资讯浏览

旗舰版强调全节点原生解锁，适合 Netflix、Disney+ 以及常见地区内容库。遇到个别标题无法播放时，先切换同区域备用节点，而不是反复重装客户端。

游戏加速

对延迟敏感的对战与更新下载，优先使用标注 IPLC 的策略组。Rhodes 旗舰版把游戏优化写进套餐，而不是额外再卖加速器插件。

学习研究与多设备同步

论文数据库、公开课与网盘同步属于长连接场景，建议打开客户端的自动选择或故障转移。基础版三台设备已能覆盖手机、电脑与平板。

操作说明

  1. 在套餐区确认流量、设备数和是否需要 IPLC / 全解锁，选择基础版、旗舰版或团队版。
  2. 完成订阅后，在账户页复制订阅链接（Clash / sing-box / 通用格式按客户端选择）。
  3. 安装对应系统的客户端，打开「订阅 / Profile / 配置」并粘贴链接，开启自动更新。
  4. 先用自动选择测试连通，再按场景把流媒体、游戏或办公域名放到指定策略组。
  5. 多设备重复导入同一订阅即可，注意不要超过套餐同时在线上限。

导入后建议检查

  • 系统代理或 TUN 模式是否开启
  • 订阅是否显示最近更新时间
  • 节点延迟测试是否完成
  • 分流规则是否误伤国内常用网站

常见问题

Rhodes 支持哪些客户端？

支持 Windows、macOS、iOS、Android、Linux 以及可导入订阅的路由器。个人侧最常用的是 Clash 系、Shadowrocket、Quantumult X、Surge 与 sing-box。先选定客户端，再导入同一份 Rhodes 机场订阅即可。

如何获取并导入订阅链接？

购买套餐后在账户中心复制订阅地址，打开客户端的订阅或配置页面粘贴保存，并打开自动更新。Clash 用户选择 Clash 格式，其他内核按提示选择通用或 SIP008 / sing-box 格式。导入成功后应能看到节点列表与更新时间。

基础版、旗舰版和团队版怎么选？

基础版面向轻度使用，100GB 与 3 台设备足够浏览和基础流媒体。旗舰版把流量提到 300GB，并加上全节点解锁、IPLC 游戏优化和优先工单，适合大多数个人用户。团队版提供 1000GB、20 台设备、高带宽节点和客户经理，适合多人同时在线。

能否解锁常见流媒体？

基础版提供基础流媒体解锁；旗舰版与团队版强调全节点原生解锁，更适合需要稳定播放的用户。若单个剧集失败，优先更换同地区节点并检查客户端分流，不必立刻更换套餐。

延迟高或连不上时先做什么？

先更换节点和协议，确认本地网络正常，并检查客户端是否过期未更新订阅。旗舰版与团队版可走 7x24 优先工单。游戏场景请明确使用 IPLC 策略组，避免把对战流量留在普通公共节点。

年付如何计算，流量会清零吗？

年付价格按约十个月计，更适合长期使用。流量按月额度刷新，不把全年流量一次性堆在第一个月。设备同时在线数始终受套餐上限约束。
